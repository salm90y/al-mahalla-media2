# Combat 3 Android build

Open `android/` as a Gradle Android project. The GitHub Actions workflow builds the debug APK.

The repository deliberately does not contain copyrighted PS1 ROMs/BIOS dumps or a proprietary emulator binary. The intended core integration is a legally distributable Libretro core built from source. User-owned game content is selected on-device.

For a production two-device match, the application-level input protocol must be connected to a deployed signaling/relay transport and tested on two physical Android devices.
